# GNS3 для РЕД ОС 8 — ССА10

Полный установочный комплект: GNS3 GUI/Server, Dynamips, uBridge, VPCS, QEMU/KVM, libvirt, Wireshark, образы Cisco c2691 и IOSvL2. Резервный c3660/NM-16ESW также включён. Для работы с настоящим виртуальным коммутатором выбирайте профиль **Full**.

## Установка одной командой

Откройте терминал **обычного пользователя** на РЕД ОС 8 x86-64 и вставьте:

```bash
curl -fsSL https://raw.githubusercontent.com/urijzubkov78-crypto/GNS3_REDOS_SSA10_PlugAndPlay/main/bootstrap.sh | bash
```

Нужны Интернет, `curl`, право `sudo`, аппаратная виртуализация Intel VT-x/AMD-V и рабочее место с 16 ГБ ОЗУ и 8 потоками CPU. Текущая предварительная проверка требует 50 ГиБ свободного места; это консервативный запас. Оценка дополнительного объёма полной установки — 3–7 ГБ, но фактический размер зависит от зависимостей в РЕД ОС и кэша пакетов.

Загрузчик скачает весь комплект с образами (около 160 МБ) в `~/.local/share/gns3-redos/project` и откроет мастер. Повторный запуск обновляет код через Git, сохраняет журналы и останавливается при локальных изменениях, которые могут помешать обновлению.

IOSvL2 хранится в репозитории тремя частями: мастер автоматически собирает их в единый `.qcow2` и проверяет MD5 перед установкой.

1. Оставьте профиль **Full** и действие **Полная установка**.
2. На экране компонентов всё уже включено: `↑`/`↓` перемещают курсор, `Пробел` переключает необязательные пункты, `Enter` продолжает.
3. Подтвердите установку и импорт образов латинской `y`. Введите свой пароль `sudo`, когда его запросят; символы пароля на экране не отображаются.
4. После завершения перезагрузите компьютер и проверьте результат:

```bash
bash ~/.local/share/gns3-redos/project/setup.sh --profile full --verify
```

До нового входа в сеанс проверка групп KVM/libvirt/gns3lab может завершиться ошибкой. После входа ожидается `Failures: 0`. Другие ошибки нужно исправить по журналу.

## Первый запуск GNS3

Запустите GNS3 от того же обычного пользователя, который выполнял установку. Если программа уже была открыта во время установки, закройте её и запустите снова. Выберите локальный сервер: **Run appliances on my local computer**.

Мастер автоматически регистрирует устройства. В списке слева появятся:

- **SSA10 Cisco 2691 Router** — маршрутизатор для HQ-RTR/BR-RTR;
- **SSA10 Cisco 2691 ISP** — маршрутизатор ISP с дополнительным портом;
- **SSA10 Cisco IOSvL2** — коммутатор для HQ-SW/BR-SW.

Перетаскивайте устройства на рабочее поле. Регистрация выполняется для текущей учётной записи; повторный запуск проверяет регистрацию без дублей, сохраняя настройки существующих шаблонов. Для маршрутизаторов подберите **Idle-PC**, чтобы снизить загрузку CPU. В резервном профиле вместо IOSvL2 появится **SSA10 Cisco EtherSwitch**: это c3660 с модулем NM-16ESW, его возможности отличаются от IOSvL2.

## Где файлы и журналы

| Что | Где |
|---|---|
| Комплект и исходные образы | `~/.local/share/gns3-redos/project/images` |
| Установленные образы | `/opt/gns3/images/IOS` и `/opt/gns3/images/QEMU` |
| Ссылка на установленные образы | `~/GNS3/images` |
| Шаблоны устройств | `~/GNS3/appliances/ssa10-*.gns3a` |
| Журнал каждого запуска | `~/.local/share/gns3-redos/project/logs/run-ДАТА-ВРЕМЯ-PID/install.log` |
| Краткий итог запуска | В той же папке, `summary.txt` |
| Ошибки скачивания комплекта | `~/.local/state/gns3-redos/bootstrap-*.log` |

В журнале есть время, этапы, вывод программ и место сбоя; в отчёте — результат, код выхода, длительность и выбранные компоненты. Коды ошибок сохраняются. Пароли не запрашиваются через журнал; распространённые токены и параметры доступа URL маскируются. При обращении за помощью приложите `install.log` и `summary.txt`, предварительно просмотрев их содержимое.

Образы имеют исходные имена `c2691-entservicesk9-mz.124-13b.bin` и `vios_l2-adventerprisek9-m.ssa.high_iron_20200929.qcow2`. Префикс `ssa10` относится к шаблонам, которые создаются после импорта образов.

## Если образов или шаблонов нет

Повторите только импорт, затем проверку файлов:

```bash
cd ~/.local/share/gns3-redos/project
bash setup.sh --profile full --images
sudo find /opt/gns3/images -maxdepth 2 -type f -printf '%p\n'
sudo sha256sum -c /opt/gns3/images/SHA256SUMS
```

Если образы уже есть, а устройств в GNS3 нет, обновите комплект и повторите только создание и регистрацию шаблонов. Запускайте команды от того же обычного пользователя:

```bash
cd ~/.local/share/gns3-redos/project
git pull --ff-only origin main
bash setup.sh --profile full --templates
```

После завершения откройте GNS3 или перезапустите уже открытую программу. Эта команда использует установленные образы, системные программы повторно не устанавливает. Для резервного профиля замените `full` на `dynamips`.

Резервный ручной способ: **File → Import appliance**, затем по очереди выбрать `ssa10-c2691-router.gns3a`, `ssa10-c2691-isp.gns3a` и `ssa10-iosvl2.gns3a` из `~/GNS3/appliances`.

Для запуска из скачанной папки достаточно `bash setup.sh`. Проверка самого комплекта без установки системных программ: `bash scripts/selftest.sh` и `python3 -m unittest discover -s tests -v`.
